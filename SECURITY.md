# Security Policy

## Supported versions

The latest release of each repository in this organization receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Email **contact@trenstudio.com** with:

- the affected repository and version,
- a description of the issue and its impact,
- reproduction steps or a proof of concept.

We acknowledge reports within 3 business days.

## Scope

This policy covers every repository under the **TREN-Studio** organization.
